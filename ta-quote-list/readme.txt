Lista privada de cotización para WooCommerce con envío a vendedores y compra masiva.

Versión 0.1.0 — Hornero.

== Description ==

Agrega un botón Cotizar independiente del carrito. Cada visitante mantiene una lista privada en su sesión de WooCommerce. La lista incluye miniatura, SKU, nombre, descripción corta, cantidad, precio, impuestos y totales.

Funciones del MVP:

* Lista aislada por sesión.
* Cantidades enteras con valor predeterminado 1.
* Eliminación con opción Deshacer.
* Vista adaptable para móviles e impresión.
* Solicitud registrada en WooCommerce > Cotizaciones.
* Aviso por correo al administrador y confirmación al cliente.
* Transferencia masiva al carrito mediante Quiero comprar ahora.
* Estado completo o parcial del envío al carrito.

== Installation ==

1. Instalar y activar WooCommerce.
2. Subir el ZIP desde Plugins > Añadir plugin > Subir plugin.
3. Activar TA Lista de Cotización para WooCommerce.
4. El plugin crea automáticamente la página Mi cotización.
