# Hornero v0.6.6 Golden Baseline

Esta carpeta preserva la implementación aprobada de **TA Cotizador de Productos v0.6.6 "Hornero"**.

La referencia contractual es `docs/GOLDEN-BASELINE-v0.6.6.md`. Toda versión posterior debe pasar `tests/REGRESSION-MATRIX.md` antes de considerarse compatible/estable.

Se preservan dos artefactos binarios:

- el ZIP instalable exacto de v0.6.6;
- un paquete completo de preservación que incluye código fuente, documentación, prompt maestro, especificaciones, checksums y pruebas.

**Regla de oro:** ninguna versión futura puede quitar, alterar o degradar una funcionalidad existente de v0.6.6 salvo que el requerimiento de esa versión lo autorice explícitamente.
